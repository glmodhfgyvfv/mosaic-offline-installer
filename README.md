# Mosaic — Free Offline Installer

![Category](https://img.shields.io/badge/Window_Manager-blue?style=flat-square)

## About

Mosaic is a macOS window management application with a layout-based approach. Define custom window layouts and apply them with a single click or keyboard shortcut to arrange multiple windows precisely. Create saved layouts for different workflows and switch between them instantly. Mosaic's visual layout editor and named workflow support make complex multi-window arrangements reproducible.

## Common Problems & Limitations

- **macOS Only** — No Windows version
- **Commercial License** — Paid application
- **Layout Complexity** — Creating complex multi-window layouts requires initial setup investment
- **Window Detection** — Some applications with non-standard windows may not resize correctly
